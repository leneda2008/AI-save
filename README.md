# NOVA — Modern E-commerce Website

NOVA is a modern e-commerce website designed to provide users with a smooth and enjoyable online shopping experience.

## Features

- Modern homepage design
- Product listings
- Product comparison
- Shopping cart
- Wishlist
- Order tracking
- Responsive layout

## Technologies Used

- HTML
- CSS
- JavaScript

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
